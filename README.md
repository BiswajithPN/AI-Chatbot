# 🚗 AV-OS - Autonomous Vehicle AI Chatbot

## Quick Start

```bash
python app.py
```

Open `http://localhost:5000` in your browser.

## Features

- **Professional Loading Animation**: Sleek blue car driving across the screen
- **Autonomous Vehicle AI**: Specialized chatbot for self-driving technology
- **Real-time Responses**: Powered by Groq API
- **Modern UI**: Dark theme with cyan accents

## What's Included

- **Loading Screen**: Premium animated blue car with glowing effects
- **Chat Interface**: Clean, professional design
- **AI Assistant**: Expert-level responses on autonomous vehicles

## Requirements

- Python 3.8+
- Groq API Key (get from https://console.groq.com/keys)

## Setup

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Create `.env` file with your Groq API key:
   ```
   GROQ_API_KEY=your_api_key_here
   ```

3. Run the app:
   ```bash
   python app.py
   ```
